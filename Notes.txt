Setup
- Create virtual environment .venv dir, .venv\Scripts\activate
- Install requirements.txt
  - Install uagents library
  - Install python-dotenv
  - Install openai
- Create .env
- Agent Setup
  - Setup API key on ASI:One platform
  - Setup seed value
  - Setup mailbox feature
    - mailbox=True
    - Run the agent
    - Click inspector link in terminal
    - Connect it with mailbox

Running the Agent
- Agent runs locally, using your machine as a server
- Other agents on the verse can effectively chat with your agent 
  in real-time through the mailbox feature (essentially a reverse-proxy)

Chat protocol
- Uses on_message event handler
  - Handler Function parses input, generates response and sends back
- ASI:One LLM API >> OpenAI agent SDK
